This repository only holds Lyricopter's releases (installers and update feed). The source code is private.

## Windows

1. Open the [latest release](../../releases/latest) and download **`Lyricopter-<version>-setup.exe`** (under *Assets*). Run it.
2. Windows may show *"Windows protected your PC"* because the app isn't code-signed: click **More info → Run anyway**.
3. Play a song in Spotify — the lyrics appear on your desktop. The settings window opens on first launch; later open it from the ♪ icon in the system tray.

No account needed. Prefer no install? Take the `-portable.exe` from the same page. To move or resize the lyrics, press `Ctrl+Alt+L`.

## macOS (preview)

Use the matching DMG or ZIP: arm64 for Apple silicon, x64 for Intel. DMG installs go into Applications.
These previews are ad-hoc signed, without Developer ID signature or Apple notarization. Try Finder → right-click → Open; if macOS still
blocks it, review Privacy & Security → Open Anyway only after checking the download's source.

On first player access, allow Lyricopter to control Spotify/Music in **System Settings →
Privacy & Security → Automation**. It only reads track metadata/position/artwork and does not
launch players.
